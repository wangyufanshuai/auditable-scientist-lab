# T1 combined CLI Run v2

`python -m auditable_scientist init <config>` writes the bundled offline Hohmann fixture. `python -m auditable_scientist run <config> --offline --seed 17` creates one versioned Run with two registered calls: the bounded analytic candidate evaluator and a pure-Python RK4 two-body propagation evaluator. The installed `auditable-scientist` command uses the same version router. `replay`, `inspect`, and `export-report` select the source version bound in each Run manifest.

The v2 Run snapshots its dataset, source files, environment, seed, candidate order, both computational results, Run hash, Evidence, append-only Events, and Trace in a portable manifest. Replay recomputes both evaluators and the study contracts, checks the saved Run's expected semantics, and fails if result, input snapshot, event chain, Claim, source, or report bytes differ. `inspect` and `export-report` verify replay before reading or copying an artifact; deleting the numerical result cannot route those commands through the legacy CLI. The [combined Run audit](../artifacts/t1-combined-cli-audit-v4.json) checks relocation and mutation controls. The [wheel audit](../artifacts/wheel-audit.json) installs the package outside the checkout and replays the Run families.

Historical Runs bind the old `pyproject.toml` or `__main__.py` bytes. The v3 router keeps a SHA-256-pinned archive made from Git commit `8c26a26` and executes those Runs in an isolated temporary source tree. The archive contains no old Run evidence; every Run still verifies its own input, source, environment, event chain, and output. The router validates a copied Run before `inspect` or `export-report` and leaves the original files untouched. New Runs bind the current source bytes. Both paths remain offline.

The formula Claim is `validated-reproduction` only within the declared local circular two-body fixture when the fixed holdout and numerical gates pass. The mission Claim remains `unverified` at `demo` level. Vis-viva supplies the departure speed. This Run does not validate a dated Mars trajectory, source rights, real-data provenance, general orbital dynamics, scientific novelty, or publication readiness.
