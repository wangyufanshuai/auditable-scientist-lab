# T1 combined CLI Run v2

`python -m auditable_scientist init <config>` writes the bundled offline Hohmann fixture. `python -m auditable_scientist run <config> --offline --seed 17` creates one versioned Run with two registered calls: the bounded analytic candidate evaluator and a pure-Python RK4 two-body propagation evaluator. `replay`, `inspect`, and `export-report` operate on that Run. The new package entry point also delegates old T1 and T2–T5 replay to the unchanged historical CLI.

The v2 Run snapshots its dataset, source files, environment, seed, candidate order, both computational results, Run hash, Evidence, append-only Events, and Trace in a portable manifest. Replay recomputes both evaluators and the study contracts, checks the saved Run's expected semantics, and fails if result, input snapshot, event chain, Claim, source, or report bytes differ. `inspect` and `export-report` verify replay before reading or copying a v2 artifact; deleting the numerical result cannot route those commands through the legacy CLI. The [combined Run audit](../artifacts/t1-combined-cli-audit-v3.json) checks relocation and mutation controls. The [wheel audit](../artifacts/wheel-audit.json) installs the package outside the checkout and replays both the new and historical Run families.

The `auditable-scientist` console script still points to the historical `cli.py` because its exact bytes and `pyproject.toml` are bound by committed legacy replay manifests. Changing either in place would invalidate those manifests. The package module command is the versioned T1 CLI; routing the console script to it requires an explicit legacy-source migration and separate acceptance. Both paths remain offline.

The formula Claim is `validated-reproduction` only within the declared local circular two-body fixture when the fixed holdout and numerical gates pass. The mission Claim remains `unverified` at `demo` level. Vis-viva supplies the departure speed. This Run does not validate a dated Mars trajectory, source rights, real-data provenance, general orbital dynamics, scientific novelty, or publication readiness.
