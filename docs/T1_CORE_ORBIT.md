# Offline T1 two-body propagation audit

The [core orbit receipt](../artifacts/t1-core-orbit-audit.json) recomputes all nine synthetic Hohmann cases with a pure-Python fixed-step RK4 integrator. It uses the same dimensionless Cartesian two-body equation as the optional SciPy audit, but requires no NumPy, SciPy, network, or external data. The initial tangential speed comes from the analytic vis-viva relation. Thus the propagation time is independently checked; the transfer model and departure state are not independently derived.

For each case, the integrator searches at most four analytic half-periods with 2,048 and 4,096 steps. The first positive-time outward-to-inward crossing of $\boldsymbol r\cdot\boldsymbol v$ is located by 40 bisections, each reintegrating from the preceding state. The analytic flight time is used only after propagation to evaluate error. Both resolutions must detect apoapsis; each finer time error must be less than one quarter of the coarser error. Relative time, final Cartesian position and velocity, maximum energy and angular-momentum drift, and coarse-to-fine time difference must each remain below $10^{-9}$. A repulsive-force control must produce no apoapsis in its finite search window.

Run `python scripts/verify_t1_core_orbit.py --verify` to recompute the exact saved receipt, including source fingerprints and the local Python version. `python scripts/verify_acceptance.py` recomputes it again in the core environment. The source is bundled in the wheel, but the historical core CLI Run is still analytic and does not include this integrator as a registered Tool/Provider call. A versioned Run migration with replay and tamper checks is required before closing that gate.

All nine cases are synthetic circular-orbit fixtures, and the declared holdout labels are inherited from the fixture. This audit does not use dated ephemerides or establish a Mars mission trajectory, real-data validity, publication readiness, or a physical claim beyond the idealized two-body calculation.
