# T2 independent synthetic endpoint estimate

The existing T2P simulator advances a ball over a fixed sampling grid and resolves floor impacts inside each grid step. This optional check computes the horizontal endpoint with a separate impact-to-impact recurrence. It does not call the grid simulator to produce an estimate. At each impact, it advances horizontal position by $v_x t$, applies $v_x^+=(1-\mu)v_x^-$, and repeats until the horizon or the declared event cap. The next impact interval solves the ballistic quadratic from the current height and vertical speed. Both paths implement the same declared synthetic model, so agreement tests implementation consistency, not independent physical validity.

The input combines the committed 100 T2P cases (40 train, 60 holdout) with 24 deterministic extra holdout cases varying initial height, horizontal and vertical speed, mass, friction, restitution, gravity, impulse, and horizon. The latter include single-parameter, joint, and policy interventions. [The varied input](../artifacts/t2-independent-endpoint-input.json) is generated by a bounded deterministic rule in the audit script and must match it byte-independent after JSON parsing.

For each case, the estimator computes factual and intervened final horizontal positions separately, then takes their contrast. The [audit](../artifacts/t2-independent-endpoint-audit.json) compares those values with the existing grid simulator's two branches. Required gates are at most $10^{-8}$ m absolute error for either endpoint and their effect, at most $10^{-8}$ m holdout effect RMSE, and an ignored-intervention holdout RMSE above $0.01$ m. `python scripts/verify_t2_independent_endpoint.py --verify` recomputes all 124 cases, checks source bytes and boundaries, and rejects a changed receipt. Training cases are not used to tune this fixed estimator.

This is paired counterfactual computation **inside** a fully specified simulator. It does not estimate effects from observational data, measure real intervention outcomes, establish exchangeability in a population, quantify physical-model discrepancy, or resolve the source-rights and external-algorithm gates. No real-data, research-candidate, publication, or deployment claim follows from passing this check.
