# T4 exact linear-invariant proof slice

This optional slice checks a broader class than the fixed two-state transfer witness. A declared linear transition has state $x\in\mathbb{Q}^n$, control $u\in\mathbb{Q}^m$, and $x'=Ax+Bu$. For a declared linear quantity $I(x)=cx$, the identity $I(x')=I(x)$ holds for **every** state and control exactly when $cA-c=0$ and $cB=0$. Those coefficient equalities are a finite, exact certificate for this linear class. The checker parses only canonical rational strings and computes with Python `Fraction`; it does not use floating-point tolerances.

[The input](../artifacts/t4-linear-systems-input.json) declares two positive examples: a two-compartment transfer and a three-compartment exchange with a nonidentity permutation matrix. It also declares a leaky exchange negative control. Each has one finite sample state and control. Samples demonstrate the transition and give a concrete counterexample for the leaky system; the universal positive result comes from the coefficient equalities, not from the sample.

`python scripts/verify_t4_linear_formal.py --verify` recomputes the [audit and certificates](../artifacts/t4-linear-formal-audit.json) with SymPy's exact rational matrix operations. `python scripts/check_t4_linear_certificate.py` independently rechecks every certificate with standard-library `Fraction`, including matrix dimensions, source-input binding, coefficients, sample transition, and negative-case classification. The portfolio acceptance command invokes both checks. The audit binds input, script, checker, and existing T4 rule source bytes with SHA-256. A missing, duplicated, altered, noncanonical, or out-of-scope certificate fails closed.

This proves only declared rational **linear** invariants of declared matrices. It does not establish that a physical process obeys those matrices, that arbitrary controls preserve nonnegative state, that a floating-point simulator implements them, or that nonlinear dynamics satisfy the invariant. The existing T4 finite trajectory witness remains separate. The project's general formal-backend, reviewed physical model, real-world data, and human acceptance gates remain open.
